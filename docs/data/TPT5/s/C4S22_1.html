Section 22.1
Auditory System

1.0  CPT CODES
69000 - 69990, 92620, 92621, and 92625
2.0  DESCRIPTION
The auditory system pertains to the sense of hearing.
3.0  POLICY
Services and supplies required for the diagnosis and treatment of illness or injury involving the auditory system are covered.
4.0  EXCLUSION
Benefits are not payable for a pulse generator system for the tympanic treatment of inner ear endolymphatic fluid (Healthcare Common Procedure Coding System (HCPCS) code E2120).

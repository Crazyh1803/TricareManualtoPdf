TRICARE Systems Manual 7950.4-M, April 2021
TRICARE Duplicate Claims System (DCS) - TRICARE Encounter Data (TED) Version
Chapter 4
Section 1.4
System Implementation And Operational Requirements
Revision:  C-24, April 8, 2025
This section describes implementation requirements for the Duplicate Claims System (DCS). It also defines policies and procedures for the operation of the system. For transition requirements related to this section, see the TRICARE Operations Manual (TOM), Chapter 2.
1.0  System Components
The DCS is a web-based application operating as a customized graphical user interface. The application runs under Microsoft® Internet Explorer (MSIE) in accordance with Chapter 1, Section 1.1.
2.0  Software Requirements
2.1  Optional Software
The contractor may, at it’s own option and expense, procure and utilize full version database management software packages such as Microsoft Access®, dBase®, Paradox For Windows®, etc., on the DCS PCs for the purpose of generating customized queries and reports utilizing optionally downloaded ASCII fixed length files that can be created by the DCS. Downloaded ASCII fixed length files may also be imported into Microsoft Excel®.
2.2  Security and Access Requirements - Defense Health Agency (DHA) Form 834, Patient Encounter Processing and Reporting (PEPR) Account Activation Request Form
2.2.1  The contractor shall identify an Information Security Officer to oversee the DCS registration process. DCS registration requires the submission of one application, for each user through Enterprise Common Access Card (CAC) Registration Service (ECRS): https://sso.csd.disa.mil/amserver/UI/Login?org=cac_pki&authlevel=3&ecrs= true&goto=https://sso.csd.disa.mil/idm/mhs/CACRegistration.do. Each DCS user shall complete the electronic form and provide the required information, i.e., certification of completion of IA training.
2.2.2  In order to access the DCS and ECRS, users shall obtain a CAC from Defense Health Agency (DHA), see Chapter 1, Section 1.1. CACs will be issued following receipt and processing of properly completed registration and security forms.
2.2.3  The contractor shall provide the required information, and submit the completed form to their DCS Information Security Officer for signature and transmittal to DHA.
2.2.4  DCS data shall be encrypted. Encryption specifications will be provided by DHA. See Chapter 1 for additional security and communications requirements.
2.3  Registration and Security
Individual users require ECRS registration to access DCS. Users creating DCS reports will also be required to register for Business Objects XI (BOXI). The contractor’s identified users shall complete and sign Government provided security and access forms prior to be granted DCS access the on-line registration for DCS and BOXI access, as appropriate. Users may register for DCS and BOXI access on the same request.
3.0  Connectivity
The contractor shall connect to DCS through the Internet to the Patient Encounter Processing and Reporting (PEPR) Portal via MSIE, Version 5.5, 6.0, or 7.0, or as directed by the Government.
4.0  System Support
The contractor shall file a problem ticket with the DHA Global Service Center at 1-800-600-9332, then follow the prompts to the DCS, for DCS support.

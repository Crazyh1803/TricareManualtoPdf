1.0  CPT CODES
Fluoroscopic Guidance: 77001 - 77003
Computed Tomography Guidance: 77011 - 77014
Magnetic Resonance Guidance: 77021 and 77022
Radiologic Other: 77031 and 77032
2.0  Description
2.1  Use of a fluoroscopy to examine deep structures by means of x-ray; it consists of a fluorescent screen covered with crystals of calcium tungstate on which are projected the shadows of x-rays passing through the body placed between the screen and the source of radiation.
2.2  Fluoroscopic guidance (Current Procedural Terminology (CPT) code 77001) for central venous placement, replacement or removal may be considered for cost-sharing. Fluoroscopic guidance (CPT code 77002) for needle placement (e.g., biopsy, aspiration, injection, localization device) may be considered for cost-sharing. Fluoroscopic guidance (CPT code 77003) and localization of needle or catheter tip for spine or paraspinous diagnostic or therapeutic injection procedures may be considered for cost-sharing.
2.3  Computed tomography guidance (CPT code 77011) for stereotactic localization, for guidance of needle placement (CPT code 77012); for guidance and monitoring of parenchymal tissue ablation (CPT code 77013); for guidance for placement of radiation therapy field (CPT code 77014) may be considered for cost-sharing.
2.4  Magnetic resonance guidance for needle placement (CPT code 77021); for guidance and monitoring of parenchymal tissue ablation (CPT code 77022) may be considered for cost-sharing.
2.5  Stereotactic localization guidance for breast biopsy or needle placement (CPT code 77031) may be considered for cost-sharing.
2.6  Mammographic guidance for needle placement for wire localization or for injection, breast may be considered for cost-sharing (CPT code 77032).

1.0  SUBMISSION REQUIREMENTS
1.1  The DD Form 1423, Contract Data Requirements List (CDRL) identifies all the required information necessary for providing data to the Government including file format; submission information; frequency; distribution; and content details. The CDRLs are located in Section J of the applicable contract.
1.2  The contractor shall submit deliverables that provide data for measuring objective requirements in Microsoft® Excel format with metric data reported in the same cell within the same worksheet for each reporting period. For these reports, a report template will be provided by the Government prior to the start of the first reporting period. The Government will provide updated templates as needed.
1.3  The contractor shall distribute deliverables to other organizations (Government and contractors) as specified by the Government.
1.4  The contractor shall submit all deliverables in one of the following file formats:
•  Microsoft Word (.doc)
•  Microsoft Word Open XML (.docx)
•  Microsoft Excel (.xls)
•  Microsoft Excel Open XML (.xlsx)
•  Microsoft Excel Macro-Enabled Workbook (.xlsm)
•  Microsoft PowerPoint (.ppt)
•  Microsoft PowerPoint Open XML (.pptx)
•  Adobe Portable Document Format Text-Only (.pdf)
•  Plain Text (.txt)
•  Comma Separated Values (.csv)
•  Rich Text Format (.rtf)
•  HyperText Markup (.html/.htm)
•  Microsoft Project (.mpp)
1.5  The contractor shall not submit deliverables that are password protected, encrypted, or have embedded images.
2.0  METHOD OF SUBMISSION
The Defense Health Agency (DHA) E-Commerce Extranet application facilitates the submission and tracking of contract deliverables. The contractor shall submit all required deliverables to the DHA via the E-Commerce Extranet unless otherwise directed by DD Form 1423, CDRL, located in Section J of the applicable contract.
2.1  Users access the application via the Internet through a workstation browser. The application is a “thin client”, meaning that no software needs to be installed on the client workstation and no software is downloaded into the browser. Javascript and cookies must to be enabled in the browser to utilize the application.
2.2  The application is best viewed at a resolution of 1024 x 768 pixels in an Internet Explorer (IE) browser (Version 8 and higher). The Extranet application also supports the use of Chrome. Users must access the application using the Secure Socket Layer (SSL) protocol (https://) and a Common Access Card (CAC) with the Personal Identy Verification (PIV) Authentication certificate. The Extranet application is Internet Protocol (IP) address restricted, i.e., it only allows communications from user organizations using defined and known IP addresses.
2.3  The contractor shall request access to the Extranet using the E-Commerce User Access Request-External which will be provided by the Government. The User Access Request must list the organization IP address from which data is transferred to/from the Extranet application.
2.4  Access to deliverables is granted to users at the contract level and deliverables submitted by one contractor will not be accessible to any other contractor.
